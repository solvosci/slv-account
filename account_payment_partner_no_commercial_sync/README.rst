This module prevents Payment Terms and Payment Modes from automatically
propagating from a company to its contacts/addresses. It decouples the
standard Odoo and OCA account_payment_partner inheritance
(\_commercial_fields) for these fields, leaving each contact with
independent values.

Known issues / Roadmap
======================

Current
-------

- Decouple payment terms and payment modes from
  ``_commercial_fields()``.
- Ensure company changes do not overwrite child contacts/addresses.

Future
------

- Implement conditional inheritance:

  - Update child only if its value matched the parent previously.
  - Preserve differentiated child values.
